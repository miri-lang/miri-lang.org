Repairs — miri fix

A repair is an edit the compiler is sure of. When a diagnostic carries one, miri fix can write it. Without --apply it only shows what it would do:

{% include agents/run.html session="fix-preview" step=0 %}

miri fix FILE --apply --yes writes every repair in the file in one go. (--yes confirms the write when there is no terminal to ask at, which is always the case for an agent.)

How safe is a repair?

Every diagnostic code has a fixSafety level. miri fix --apply writes the first three on its own and refuses the rest unless you add --allow-risky:

LevelMeaningApplied by default
format-onlyChanges layout only.yes
behavior-preservingChanges the text, not what the program does.yes
local-editChanges one spot, and nothing outside it can notice.yes
api-changingChanges something other code relies on, such as a parameter name callers can pass by name.no
target-changingChanges where or how the program runs, such as moving data to the GPU or narrowing a number.no
requires-human-reviewPlausible, but a person should look first.no
