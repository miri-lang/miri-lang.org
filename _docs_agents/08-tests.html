Tests — miri test

Mark a function with @test and miri test finds and runs it. Each test runs in its own process, so a crash fails one test instead of the whole run. Here is a file with a deliberately wrong expectation in its second test:

{% include agents/example.html file="scores.mi" %} {% include agents/run.html session="test" step=0 %}

With --format json, each failure carries the code, the line and the expected and actual values, ready for the agent to compare:

{% include agents/run.html session="test" step=1 %}

The exit status says what happened: 0 all passed, 1 a test failed, 2 no test ran at all (a file did not compile, or there were no tests). An agent can trust a 0: a run that found nothing to test is never reported as a pass. The miri-testing pack covers assertions and test attributes.
