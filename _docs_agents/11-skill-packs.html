The Skill Packs

A skill pack is a short Markdown file in the Agent Skills format: a name, a one-line description that tells the agent when to open it, and the guide itself. They ship inside the compiler, so the packs you install always match the compiler you run. Below is the full text of each, exactly as an agent reads it.
