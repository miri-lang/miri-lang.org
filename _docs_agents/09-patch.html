Scoped Edits — miri patch

miri patch replaces text inside one named function, then checks the whole file before saving. A good edit is written:

{% include agents/run.html session="patch" step=0 %}

An edit that would break the file is refused, and the file is left exactly as it was:

{% include agents/run.html session="patch" step=1 %}

The text to replace must appear exactly once inside the function. patch works on files in Miri's standard layout, so run miri fmt FILE first if the file was written by hand. Ordinary file edits work just as well; patch is there for when you want the check before anything is saved.
