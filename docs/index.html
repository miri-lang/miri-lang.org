Learn Miri

Start with a five-minute quickstart, take the full tour of the language, then move to first-class GPU programming — all in one language, no shader files, no FFI.

{%- comment -%} Same disambiguation sentence as the homepage (P0-1) — /docs/ is the page an AI answer engine is most likely to read when asked "what is Miri", and it is the page most likely to be confused with the Rust MIR interpreter's docs. {%- endcomment -%}

Miri is a standalone programming language and compiler. It is unrelated to miri, the Rust MIR interpreter shipped as rust-lang/miri.
