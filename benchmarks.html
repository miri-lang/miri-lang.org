Benchmarks

How fast is Miri, and how much memory does it use?

The same programs in seven languages, built the way each language ships, run on one machine under rules that were written and committed before the first measured run. Where Miri loses, the loss is listed with the compiler mechanism responsible.

The rules

  • Every port computes the same thing from the same input bytes and prints the same checksum; a port that prints anything else is not a data point.
  • Each port is idiomatic, single-threaded code with the language's standard containers: no SIMD intrinsics, no unsafe, no arenas or hand-rolled hashes.
  • Each language is built with its default optimized build; the exact command lines and toolchain versions are recorded with every run.
  • Two times are reported: the whole process, start-up included, and the hot kernel after a warm-up, so neither start-up nor a JIT's warm-up can hide.
  • Memory is peak resident memory, shown beside each toolchain's own floor so a runtime's fixed cost is not folded into the workload.

The full rules are the benchmark charter (version {{ run.charter_version }}); the programs, the runner and the raw records are in bench/.
